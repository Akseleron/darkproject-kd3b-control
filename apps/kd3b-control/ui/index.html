FACTORY / ONBOARD

Fn-слой и встроенные профили

Не смешиваем с host-профилями

У семейства Dark Project этого поколения есть Default Layer, Fn-слой и встроенная память. Для KD3B rev.2 точные заводские назначения и протокол чтения/записи ещё не восстановлены, поэтому приложение их не перезаписывает и не изображает известными.

Default LayerЗаводская базовая раскладка. Отображение и безопасный readback ещё предстоит восстановить.
Fn LayerOEM ПО этого поколения отдельно редактирует Fn1 Layer, включая мультимедиа. Точный KD3B набор нужно подтвердить.
Onboard profilesЕсть свидетельства нескольких аппаратных профилей у семейства KD1/KD3 rev.2. Точные сочетания KD3B не хардкодим без модельного источника или capture.
Macros / remapОставлены read-only boundary до восстановления формата и семантики persistence.
